GNSS File Downloads
===================================================================

SP3 download setup is shared by the Python and C++ interfaces. See the
standalone :doc:`SP3 download page <../../pages/sp3_download>` for Earthdata
Login, ``~/.netrc``, cache-location, and troubleshooting instructions.

Quick commands:

.. code-block:: bash

   pixi run download-sp3-example
   pixi run download-sp3-example-cpp
